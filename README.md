# English DO/DOES Interactive Material

A simple, interactive web-based learning material for English grammar focusing on the use of **DO** and **DOES** in the Simple Present Tense.

This project includes:
- Clear rules and explanations.
- Examples and common mistakes.
- An interactive quiz with 10 questions to test your knowledge.

## How to use
Simply open `index.html` in your web browser.

## Technologies Used
- HTML5
- TailwindCSS (via CDN)
- Vanilla JavaScript
